Terms used on this page

Landed means merged to main. Landed share divides those merges by all write tasks, including failed attempts. Low sample means fewer than 10 observations in the relevant denominator.

An interval is the 95% Wilson interval for a share. Wide intervals signal uncertainty, and overlapping intervals alone cannot settle a comparison.

A first-round approval means the first reviewer approved the PR. P0–P2 are findings from the highest priority through P2. A dash means the records lack a value for that metric.

Per-task and per-PR links are omitted because the page feed carries no task ids or private repository identifiers.

How providers report tokens

Codex fresh input is input minus cache reads. Claude, Cursor and OpenCode add cache writes to fresh input. AGY reports fresh input directly. Cached input counts cache reads. Add the separate thinking or reasoning counter to output for AGY, Cursor and OpenCode. Codex and Claude output already include it.

Rates divide recorded tokens for work that settled in the window by PRs observed merging in the same window. Rates need readable local origin/main history for every registered repository. Cache hit is cached input divided by fresh plus cached input. Token volume does not measure price.

Reviewer strictness

Higher points approve more often, and points farther right report more P0–P2 findings per review with a findings count. Compare similar assignments and read the intervals before calling a reviewer strict or lenient.

Reviewer accuracy

Each blocking (P0–P1) finding counts as fixed when the author changed its file before the same reviewer approved, and as dismissed when that reviewer approved with the file unchanged. Higher precision means more of a reviewer's blocking findings led to a change; check the settled count and interval before comparing reviewers. Only verdicts the recorder published count: a blocking reply with no recorded publication is of unknown publication and is left out. The author labels follow the table.
